# Done checklist

Before calling a task done:

1. `npm run type-check` — clean.
2. `npm run lint` — clean.
3. `npm test` — green.
4. `npm run check:size` — no file over 250 lines.
5. The view renders at 390px, 768px and 1440px with no horizontal scroll.
6. Every interactive element is reachable and visible on Tab.
7. No raw colour, no `any`, no new comment outside the policy.
8. If a note changed: nothing in it identifies an employer's internal work.
9. The diff is one concern, and the commit message says why.
